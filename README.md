# EAL Word Builder

Student-facing vocabulary and morphology practice.

This repository is the **public deployment only**. It contains the browser runtime and generated student-facing vocabulary data. Raw Word/Excel/PDF sources, study designs, translation working files, build tools, planning notes and other context belong in the private `ELC` repository.

## Privacy

No account is required. The public build does not connect to a student database. Progress is stored in this browser with `localStorage`; see `PRIVACY.md`.

## Publishing rule

Only publish files the student site actually needs. Do not add raw curriculum/source documents, personal information, teacher planning files, account infrastructure or private build context here.
